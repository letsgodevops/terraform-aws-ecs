# ECS service



## Inputs

| Name                           | Description                                                                                                                              | Type                                                                                                   | Default | Required |
| ------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------ | ------- | :------: |
| alb\_paths                     | List of custom path for alb target group                                                                                                 | `list(string)`                                                                                         | n/a     |   yes    |
| app\_generic\_config           | n/a                                                                                                                                      | `any`                                                                                                  | n/a     |   yes    |
| as\_alb\_rq\_target            | AutoScaler: Target Application Load Balancer RQs/target value for service autoscaling                                                    | `number`                                                                                               | `20`    |    no    |
| as\_cpu\_target                | AutoScaler: Target CPU value for service autoscaling                                                                                     | `number`                                                                                               | `60`    |    no    |
| as\_max\_capacity              | AutoScaler: Maximal numebr of service instances                                                                                          | `number`                                                                                               | `10`    |    no    |
| as\_memory\_target             | AutoScaler: Target Memory value for service autoscaling                                                                                  | `number`                                                                                               | `60`    |    no    |
| as\_sqs\_queue\_name           | n/a                                                                                                                                      | `any`                                                                                                  | n/a     |   yes    |
| as\_sqs\_scale\_down\_cooldown | n/a                                                                                                                                      | `number`                                                                                               | `60`    |    no    |
| assign\_public\_ip             | Assign a public IP address to the ENI. Required True for public subnets                                                                  | `bool`                                                                                                 | `true`  |    no    |
| container\_name                | n/a                                                                                                                                      | `string`                                                                                               | n/a     |   yes    |
| cpu                            | The number of cpu units to reserve for the service.                                                                                      | `number`                                                                                               | n/a     |   yes    |
| critical\_notifications        | n/a                                                                                                                                      | `list(string)`                                                                                         | n/a     |   yes    |
| custom\_imagedefinitions       | Hack! Ability to set custom imagedefinition for migration                                                                                | `string`                                                                                               | n/a     |   yes    |
| custom\_ports                  | Map of custom ports with corresponding ALB Listener                                                                                      | `map(string)`                                                                                          | `{}`    |    no    |
| desired\_count                 | (Optional) The number of instances of the task definition to place and keep running. Defaults to 1 for non-prod and 2 for prod.          | `number`                                                                                               | `1`     |    no    |
| domain                         | Domain name - required if internal\_lb or external\_lb enabled                                                                           | `string`                                                                                               | `""`    |    no    |
| entrypoint                     | The entry point that is passed to the container                                                                                          | `list(string)`                                                                                         | n/a     |   yes    |
| environment\_variables         | The environment variables to pass to all application containers                                                                          | <code><pre>list(object({<br>    name  = string<br>    value = string<br>  }))<br></pre></code>         | n/a     |   yes    |
| external\_lb                   | Enables Nginx container and Public ALB target group                                                                                      | `bool`                                                                                                 | `false` |    no    |
| force\_nginx                   | Hack! To deploy enhandced nginx version. Used to deploy main-web nginx'es                                                                | `bool`                                                                                                 | `false` |    no    |
| internal\_lb                   | Enables Nginx container and Internal ALB target group                                                                                    | `bool`                                                                                                 | `false` |    no    |
| memory                         | The amount of memory (in MiB) to allow the service to use.                                                                               | `number`                                                                                               | n/a     |   yes    |
| override\_tagret\_group\_name  | Hack! By default we have one TG per application setup. This allows to explitly overwrite app part in TG name.                            | `string`                                                                                               | n/a     |   yes    |
| role                           | n/a                                                                                                                                      | `string`                                                                                               | n/a     |   yes    |
| secret\_variables              | The secrets to pass to the container. This is a list of maps                                                                             | <code><pre>list(object({<br>    name      = string<br>    valueFrom = string<br>  }))<br></pre></code> | n/a     |   yes    |
| skip\_domain\_creation         | Hack! Skip domain creation if it was already created in different service setup. Required if you want to have different routing per path | `bool`                                                                                                 | `false` |    no    |
| ssh\_enabled                   | Open SSH Port (through Network Load Balancer) to main application container                                                              | `bool`                                                                                                 | `false` |    no    |
| task\_role\_arn                | Role used by (running) task                                                                                                              | `string`                                                                                               | n/a     |   yes    |
| warning\_notifications         | n/a                                                                                                                                      | `list(string)`                                                                                         | n/a     |   yes    |

## Outputs

| Name                           | Description |
| ------------------------------ | ----------- |
| ecs\_deployment\_configuration | n/a         |
| ecs\_service\_name             | n/a         |
| external\_url                  | n/a         |
| monitoring                     | n/a         |
